# T-023 前置：Emuera.Headless 文件结构整理方案

> 基准：[Emuera.Headless 剩余问题与行动方案.md](Emuera.Headless%20剩余问题与行动方案.md)
> 制定日期：2026-07-02
> 定位：T-023 物理迁移共享源码前的前置整理 PR，理顺 `Emuera.Headless/` 自有源码目录结构，为 T-023 的 `Shared/` 隔离方案预留边界。
> 维护范围：本项目**只维护 `Emuera.Headless`**，`Emuera/` WinForms 项目功能数年前已稳定，仅留作功能参考。

## 一、整理原则

1. **职责对齐**：物理目录与文件职责对齐，消除根目录扁平失序与 `Agent/` 混杂。
2. **namespace 不变**：物理移动不改动 namespace 声明与 using 引用，diff 最小、回滚容易。
3. **先整理自有源码**：本次 PR 只动 Headless 自有文件，T-023 作为独立 PR 处理共享源码迁移。
4. **为 T-023 预留边界**：本次产出 `Headless/`、`Terminal/` 目录边界，T-023 在此基础上新建 `Shared/` 隔离迁移源码。
5. **不动项**：`Server/`（T-024 处理 `ConsoleOutIO.cs`）、`UI/Game/Console/`、`UI/Game/EmueraConsole.cs`、`Properties/PublishProfiles/`。

## 二、决策记录

经与维护者讨论确认以下 7 项决策：

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| 1 | 共享源码迁移后的目录边界 | 迁入 `Shared/` 子目录隔离 | T-022 可按路径分级启用 nullable + TreatWarningsAsErrors |
| 2 | 根目录散落文件归类 | 建立 `Headless/` 子目录放替换实现 | 与共享源码区分，根目录只留入口/全局类 |
| 3 | `Agent/` 目录拆分 | 拆分为 `Agent/` + `Terminal/` | 协议层与终端渲染职责分离 |
| 4 | 执行节奏 | 先整理自有源码，再做 T-023 | 两个 PR diff 各自聚焦，回滚边界清晰 |
| 5 | namespace 策略 | 保持不变 | 最小 diff、回滚容易、T-023 验收只要求 build 0 error |
| 6 | `EmueraConsole.cs` 归属 | 留在 `UI/Game/` | 与 `Console/` partial 拆分同生命周期，非替换实现 |
| 7 | `Terminal/` 目录位置 | 根级 `Terminal/` | 终端渲染独立于 UI 抽象层 |

## 五、namespace 策略

- 13 个移动文件 **namespace 声明保持不变**
- 不改动任何 `using` 引用
- 代价：物理目录与 namespace 不完全一致（如 `HeadlessClipboard.cs` 在 `Headless/` 目录但 namespace 仍为 `MinorShift.Emuera.Misc`）
- 收益：diff 最小、回滚容易、T-023 验收只要求 build 0 error

长期一致性可在 T-023 后统一评估（涉及大面积 using 改动，需独立 PR）。

## 六、验收标准

1. `dotnet build Emuera.Headless/Emuera.Headless.csproj -c Debug` 0 error
2. warning 基线不变（约 140 条，移动文件不引入新警告）
3. `run_all.py --binary .../Emuera.Headless.exe --game-dir test_game` 全部回归测试通过
4. `git diff --stat` 显示纯文件移动（rename 检测率 100%），无逻辑改动
5. 检查 `obj/Debug/net10.0/Emuera.Headless.csproj.FileListAbsolute.txt` 确认 13 个文件在新位置被正确包含

## 七、风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| SDK 默认 glob 未包含新位置文件 | build 失败 | 验收标准 5 检查 FileListAbsolute.txt |
| `HeadlessConsole.cs` 移动后 IConsoleUI 实现链接断裂 | build 失败 | namespace 不变，链接不断裂；build 验证 |
| 测试夹具依赖原路径 | 回归测试失败 | `tests/` 不引用源码路径，只引用 binary；run_all.py 验证 |
| 文档链接失效 | 仓库内 .md 引用旧路径 | 本次整理同步更新 CLAUDE.md / TODO.md 路径引用；T-023 后统一刷新文档链接 |

**回滚**：`git revert` 即可，无逻辑改动、无 csproj 结构性变更。
